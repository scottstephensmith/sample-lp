# Frequently Asked Questions

## What technologies does this site use?

This site is built with:

- HTML5
- CSS3
- JavaScript
- Node.js (for building)
- Markdown for content

## How can I create a similar site?

You can find the source code for this site on our GitHub repository. It's designed to be simple to understand and modify.

## Do I need to know programming to use this?

Basic knowledge of Markdown is enough to create content. For customization, some familiarity with HTML and CSS would be helpful.

## How do I add new content?

Simply create a new Markdown file in the appropriate directory under `src/content` and rebuild the site.

## Can I use this for my own website?

Yes! This project is open source and available for anyone to use and modify.
